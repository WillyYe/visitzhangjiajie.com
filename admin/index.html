📈 百度统计配置

配置后可查看网站访客数据分析。授权流程：点击「获取 Access Token」→ 弹窗登录授权 → 页面上显示 access_token=xxx → 复制完整的 Token → 粘贴到下方 → 点击「应用 Token」。令牌有效期约 30 天。

⏳未配置
首次配置后，点击「测试连接」可自动获取站点 ID。
📋 授权步骤：
  1. 点击「获取 Access Token」按钮，在弹出的窗口中登录百度统计账号并授权。
  2. 授权成功后，页面或网址中会显示 access_token=xxxxxxxx，复制完整的 Token 值。
  3. 将 Token 粘贴到下方输入框，点击「应用 Token」。
  4. Token 自动填入上方输入框，点击「保存配置」即可。
